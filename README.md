🚀 AstroBase — Survive Beyond Earth

Explore. Survive. Discover.

AstroBase is an interactive, mobile-friendly space survival simulator designed to introduce users to the challenges of human exploration beyond Earth. Inspired by NASA's space exploration missions, the application allows users to experience survival scenarios on the Moon and Mars while managing essential resources and making mission-critical decisions.

Developed as a project for the NASA Space Apps Challenge 2026, AstroBase aims to make space science and planetary exploration more interactive, educational, and accessible.

🌌 Project Overview

Human exploration of the Moon and Mars presents significant challenges, including limited resources, extreme temperatures, radiation exposure, and the need for sustainable life-support systems.

AstroBase transforms these challenges into an interactive learning experience. Users take on the role of an astronaut, monitor survival resources, respond to unexpected mission events, and make decisions that influence the outcome of their mission.

✨ Key Features

🌕 Moon & Mars Missions: Explore survival scenarios in different extraterrestrial environments.

🫁 Oxygen Management: Monitor oxygen supplies and make decisions to maintain astronaut survival.

⚡ Energy Monitoring: Manage available energy for equipment and mission operations.

💧 Water & Food Supplies: Track essential consumables during the mission.

☢️ Radiation Protection: Learn about radiation risks and the importance of astronaut safety.

🎯 Mission Challenges: Respond to unexpected events and environmental hazards.

📊 Resource Dashboard: Monitor essential survival resources and mission status.

📋 Mission Reports: Review mission outcomes, decisions, and survival performance.

📱 Mobile-Friendly Interface: Designed to work across mobile devices, tablets, and desktops.

🪐 NASA Data Integration: Connect to NASA's public APIs and educational resources where supported by the implementation.

🎯 Project Objectives

Make space exploration concepts easier to understand through interactive simulation.

Demonstrate the importance of resource management during long-duration missions.

Introduce users to the environmental challenges of the Moon and Mars.

Encourage scientific thinking, problem-solving, and decision-making.

Promote interest in space science and future human exploration.

🛠️ Technology Stack

The project can use the following technologies, depending on the implementation in the repository:

Frontend: HTML, CSS, JavaScript, or React with TypeScript

Space Data: NASA Open APIs

API Authentication: NASA API key stored in an environment variable

🚀 Getting Started
Prerequisites

A modern web browser

Node.js and npm, if the project uses a Node.js-based framework

A NASA API key for features that require authenticated NASA API access

🪐 How It Works

Select a Mission: Choose a Moon or Mars exploration scenario.

Monitor Resources: Check oxygen, water, food, energy, and other available indicators.

Make Decisions: Respond to mission challenges and allocate resources carefully.

Handle Emergencies: Evaluate unexpected events and choose appropriate actions.

Review Results: Examine the mission report to understand the outcome of your decisions.

The specific scenarios and simulation mechanics depend on the features implemented in the application.

🌍 Educational Impact

AstroBase encourages users to explore the science behind human spaceflight, life-support systems, planetary environments, and resource sustainability.

By combining interactive challenges with space-related information, the project aims to make STEM learning more engaging while highlighting the preparation required for future lunar and Martian missions.
